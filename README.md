# 3DGS + 扩散模型 学习网站

一个完整的静态网站，整理了3D高斯泼溅（3DGS）与扩散模型融合的最新研究成果、算法实现、使用教程和研究心得。

## 🚀 网站功能

### 📚 核心内容
1. **首页概览** - 技术介绍、架构说明、关键数据展示
2. **算法实现** - 四种代表性算法的详细介绍和代码链接
   - FreeFix：无需微调的扩散增强3DGS
   - GIFSplat：稀疏视图前馈重建（快8倍）
   - ArtiFixer：遮挡区域补全与动态场景重建
   - One-Shot Refiner：单步扩散精炼（仅10%开销）
3. **性能对比** - 交互式图表和详细的性能对比表格
4. **使用教程** - 从环境安装到各算法的详细使用指南
5. **研究心得** - 技术趋势分析、工程化经验、产业应用前景

### ✨ 网站特性
- 🎨 现代化UI设计，响应式布局，支持移动端
- 📊 交互式性能对比图表
- 📝 完整的代码示例和使用说明
- 🔍 深度的技术分析和行业洞察
- ⚡ 快速加载，无需后端，纯静态网站

## 🎯 快速使用

### 方式1：直接打开
直接用浏览器打开 `index.html` 即可浏览完整网站，无需任何服务器。

### 方式2：本地服务器（推荐）
```bash
# 进入网站目录
cd 3dgs_website

# 启动简单的HTTP服务器
python -m http.server 8000
# 或
npx serve .
# 或
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000` 即可。

### 方式3：部署到线上
可以直接部署到任何静态网站托管服务：
- GitHub Pages
- Vercel / Netlify
- 阿里云OSS / 腾讯云COS
- 自己的Web服务器

## 🛠️ 技术栈

- **前端框架**：Tailwind CSS v3 - 快速构建现代化UI
- **图标库**：Font Awesome v4.7 - 丰富的图标资源
- **图表库**：Chart.js v4 - 交互式数据可视化
- **字体**：Google Fonts - Inter - 美观的无衬线字体
- **纯静态**：无需后端，无需数据库，开箱即用

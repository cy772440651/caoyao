使用代码

from 3dgs_skill import reconstruct, save_model

# 仅需4张视图完成重建
model = reconstruct(
    input_path="./data/scene",
    algorithm="gifsplat",
    num_views=4,
    device="cuda"
)

# 保存结果
save_model(model, "./output/gifsplat_model.ply")
                                
# 命令行运行GIFSplat重建
3dgs reconstruct \
    --input ./data/scene \
    --algorithm gifsplat \
    --num-views 4 \
    --output ./output/gifsplat_model.ply

适用场景： 移动端AR扫描、无人机快速建图、电商商品3D展示、快速原型设计等需要快速重建的场景。

使用代码

from 3dgs_skill import enhance, load_model

# 加载原始模型
model = load_model("./raw_model.ply")

# FreeFix增强
enhanced_model = enhance(
    model=model,
    algorithm="freefix",
    scene_path="./data/scene",
    strength=0.3,
    iterations=100
)
                                
# 命令行运行FreeFix增强
3dgs enhance \
    --model ./raw_model.ply \
    --algorithm freefix \
    --scene ./data/scene \
    --strength 0.3 \
    --output ./enhanced_model.ply

最佳实践： 对于少图重建结果，使用strength=0.4，迭代200次；对于高质量模型，使用strength=0.1-0.2，迭代50次即可获得明显提升。

使用代码

from 3dgs_skill import enhance

# 遮挡补全，支持文本提示词引导
completed_model = enhance(
    model="./incomplete_model.ply",
    algorithm="artifixer",
    prompt="photorealistic office scene, complete missing desks and chairs",
    consistency_weight=0.8
)
                                
# 命令行运行ArtiFixer补全
3dgs enhance \
    --model ./incomplete_model.ply \
    --algorithm artifixer \
    --prompt "photorealistic office scene, complete missing desks and chairs" \
    --output ./completed_model.ply

提示词技巧： 提示词需要包含场景类型、期望补全的内容、风格要求，例如"photorealistic building facade, complete missing windows, consistent architectural style"。

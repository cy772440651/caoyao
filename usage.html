使用教程

从环境配置到实际部署，一步步教你如何使用这些算法提升3D重建质量

环境安装

1. 基础依赖安装

# 创建conda环境
conda create -n 3dgs_diffusion python=3.10
conda activate 3dgs_diffusion

# 安装PyTorch
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 安装3DGS依赖
pip install plyfile tqdm numpy scipy Pillow opencv-python

# 安装扩散模型依赖
pip install diffusers transformers accelerate xformers

# 安装评估工具
pip install torchmetrics[image]

2. 编译3DGS CUDA扩展

git clone https://github.com/graphdeco-inria/gaussian-splatting.git
cd gaussian-splatting
pip install -e .

# 验证安装
python -c "import gaussian_renderer; print('3DGS installed successfully!')"

3. 下载本项目代码

git clone https://github.com/your-repo/3dgs-diffusion.git
cd 3dgs-diffusion

# 下载预训练权重（可选）
mkdir weights
# GIFSplat 预训练权重：https://drive.google.com/...
# 放入 weights/gifsplat_pretrained.pth

基础3DGS重建

首先用基础3DGS得到初始重建结果：

cd gaussian-splatting
python train.py -s /path/to/your/dataset -m /path/to/output/model

# 训练完成后，模型会保存在/path/to/output/model下

FreeFix 使用指南

无需微调的扩散增强，直接提升现有3DGS模型质量

命令行使用

python main.py \
  --algorithm freefix \
  --source_path /path/to/your/dataset \
  --model_path /path/to/pretrained/3dgs/model \
  --output_path output/freefix_result \
  --iterations 100 \
  --evaluate

Python API 使用

from FreeFix import FreeFixEnhancer
from scene import Scene, GaussianModel

# 加载模型
gaussians = GaussianModel(3)
scene = Scene(dataset, gaussians, load_path="/path/to/model")

# 增强
freefix = FreeFixEnhancer()
enhanced_gaussians = freefix.optimize_gaussians(gaussians, scene, dataset, pipe, opt)
提示：FreeFix不需要额外的训练数据，只需要已经训练好的3DGS模型即可。

GIFSplat 使用指南

稀疏视图快速重建，仅需4张输入图像

命令行使用

python main.py \
  --algorithm gifsplat \
  --source_path /path/to/your/dataset \
  --model_path /path/to/gifsplat/weights \
  --num_views 4 \
  --output_path output/gifsplat_result

输入要求

  • 至少4张带有相机参数的输入图像
  • 图像之间需要有足够的视差重叠
  • 推荐使用COLMAP提前估计相机参数
注意：GIFSplat的前馈模型需要下载预训练权重才能使用。

ArtiFixer 使用指南

遮挡区域补全，支持动态场景重建

命令行使用

python main.py \
  --algorithm artifixer \
  --source_path /path/to/your/dataset \
  --model_path /path/to/initial/3dgs/model \
  --prompt "photorealistic indoor scene, complete missing furniture" \
  --output_path output/artifixer_result

提示词工程技巧

  • 包含场景类型："indoor office", "outdoor city street", "natural landscape"
  • 描述期望的内容："complete missing walls", "fill in occluded furniture"
  • 添加风格描述："photorealistic", "high detail", "consistent lighting"
技巧：对于动态场景，可以传入时序图像序列，ArtiFixer会自动进行时序一致性补全。

One-Shot Refiner 使用指南

单步扩散精炼，提升新视角合成质量

命令行使用

python main.py \
  --algorithm oneshot \
  --source_path /path/to/your/dataset \
  --model_path /path/to/3dgs/model \
  --prompt "photorealistic, high detail, 8k" \
  --output_path output/oneshot_result \
  --evaluate

实时推理示例

from OneShotRefiner import LightweightOneShotRefiner

# 初始化轻量化版本
refiner = LightweightOneShotRefiner()

# 实时渲染流水线
while True:
  # 3DGS渲染
  rendered_image = render(camera, gaussians)
  # 单步精炼（仅增加10%耗时）
  refined_image = refiner.quick_refine(rendered_image)
  # 显示结果
  display(refined_image)
提示：One-Shot Refiner特别适合实时应用，如AR/VR场景的实时渲染增强。

常见问题

Q: 显存不足怎么办？

A: 可以尝试以下方法：1) 减小图像分辨率；2) 减少扩散步数；3) 启用VAE切片和xformers内存优化； 4) 使用更小的扩散模型，如Stable Diffusion v1.5代替v2.1。

Q: 如何选择合适的算法？

A: 如果已经有训练好的3DGS模型，优先用FreeFix；如果是稀疏视图输入，选GIFSplat； 如果场景有大面积遮挡，选ArtiFixer；如果需要实时应用，选One-Shot Refiner。

Q: 扩散模型生成的内容与实际场景不一致怎么办？

A: 可以降低扩散的strength参数（默认0.3，可调低到0.1-0.2），或者增加3D一致性损失的权重， 也可以提供更精确的文本提示词引导生成方向。

Q: 支持动态场景重建吗？

A: 是的，ArtiFixer支持动态场景和非刚性物体的时序重建，可以输入时序图像序列， 算法会自动保持时序一致性，适合人体、动物等动态对象的4D重建。

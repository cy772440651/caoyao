FreeFix - 无需微调的扩散增强

无需训练扩散模型，直接增强现有3DGS重建质量，PSNR提升1.8dB

核心特点

  • 无需微调扩散模型，直接使用预训练Stable Diffusion
  • "渲染-精炼-优化"闭环，保持原始几何结构
  • 低扩散强度(strength=0.3)，避免几何扭曲
  • 适用于所有已训练好的3DGS模型，零成本增强

使用示例

from FreeFix import FreeFixEnhancer
from scene import Scene, GaussianModel

# 加载预训练3DGS模型
gaussians = GaussianModel(3)
scene = Scene(dataset, gaussians, load_path="/path/to/pretrained/model")

# 初始化FreeFix增强器
freefix = FreeFixEnhancer()

# 优化增强
enhanced_gaussians = freefix.optimize_gaussians(
    gaussians, scene, dataset, pipe, opt,
    iterations=100
)

# 保存结果
enhanced_gaussians.save_ply("enhanced_model.ply")

命令行运行

python main.py \
  --algorithm freefix \
  --source_path /path/to/your/scene \
  --model_path /path/to/pretrained/3dgs/model \
  --output_path output/freefix_result \
  --iterations 100 \
  --evaluate

最佳实践： 对于质量较好的3DGS模型，建议使用较低的扩散强度(0.2-0.3)；对于质量较差的稀疏视图重建，可以适当提高到0.4-0.5。

GIFSplat - 稀疏视图前馈重建

仅需4张输入视图，推理速度比传统3DGS快8倍

核心特点

  • 前馈网络直接预测3D高斯参数，无需逐场景优化
  • 仅需4张输入视图，达到传统20张视图的重建质量
  • 推理时间仅需0.5秒，实现近乎实时的重建体验
  • 特别适合无人机、手持设备等少视图场景

使用示例

from GIFSplat import GIFSplatBackbone, gifsplat_inference

# 加载4张输入视图和对应相机参数
images = load_input_views(4)
cameras = load_camera_parameters()

# 前馈推理得到3DGS模型
gaussians = gifsplat_inference(images, cameras, sh_degree=3)

# 可选：生成先验引导微调
gaussians = generative_prior_finetune(gaussians, images, cameras)

命令行运行

python main.py \
  --algorithm gifsplat \
  --source_path /path/to/your/scene \
  --model_path /path/to/gifsplat/weights \
  --num_views 4 \
  --output_path output/gifsplat_result

注意： 预训练权重需要单独下载，支持通用场景、户外、室内等不同领域的专用模型。

ArtiFixer - 遮挡区域补全

自回归扩散模型补全遮挡区域，支持动态场景重建

核心特点

  • 自回归扩散模型同时补全几何和纹理信息
  • 遮挡区域重建精度提升40%以上
  • 支持动态场景和非刚性物体的4D重建
  • 多视图一致性约束，避免补全结果冲突

使用示例

from ArtiFixer import ArtiFixer3D

# 初始化ArtiFixer
artifixer = ArtiFixer3D()

# 补全遮挡区域
enhanced_gaussians = artifixer.complete_occluded_regions(
    gaussians, scene, cameras,
    prompt="photorealistic indoor scene, complete missing furniture"
)

# 动态场景时序重建
dynamic_gaussians = artifixer.reconstruct_dynamic_scene(
    image_sequence, camera_sequence
)

命令行运行

python main.py \
  --algorithm artifixer \
  --source_path /path/to/your/scene \
  --model_path /path/to/initial/3dgs/model \
  --prompt "photorealistic indoor scene, complete missing furniture" \
  --output_path output/artifixer_result

提示词工程技巧： 补全提示词需要包含场景类型、期望内容、风格描述，例如："photorealistic office scene, fill in missing desks and chairs, consistent lighting"。

One-Shot Refiner - 单步扩散精炼

仅需一步扩散提升新视角合成质量，速度仅增加10%

核心特点

  • 仅需一步扩散即可提升新视角合成质量，LPIPS降低30%
  • 3D一致性损失保持几何结构不变，避免多视角冲突
  • 推理速度仅增加10%，适合实时应用场景
  • 轻量化版本可在移动端实时运行

使用示例

from OneShotRefiner import OneShotRefiner, LightweightOneShotRefiner

# 初始化精炼器
refiner = OneShotRefiner()

# 单步精炼渲染结果
rendered_image = render(camera, gaussians)
refined_image = refiner.refine_novel_view(
    rendered_image,
    prompt="photorealistic, high detail, 8k"
)

# 轻量化版本（实时应用）
light_refiner = LightweightOneShotRefiner()
refined_image = light_refiner.quick_refine(rendered_image)

命令行运行

python main.py \
  --algorithm oneshot \
  --source_path /path/to/your/scene \
  --model_path /path/to/3dgs/model \
  --prompt "photorealistic, high detail, 8k" \
  --output_path output/oneshot_result \
  --evaluate

最佳实践： 对于实时AR/VR应用，建议使用轻量化版本，虽然质量略有下降，但可以在手机端实现30+FPS的实时渲染增强。

常见问题解答

Q: 显存不足怎么办？

A: 可以尝试以下优化：1) 减小图像分辨率；2) 减少扩散步数到20-50步；3) 启用VAE切片和xformers内存优化； 4) 使用更小的扩散模型，如Stable Diffusion v1.5代替v2.1；5) 减小batch size。

Q: 扩散模型生成的内容与实际场景不一致怎么办？

A: 可以降低扩散的strength参数（默认0.3，可调低到0.1-0.2），或者增加3D一致性损失的权重， 也可以提供更精确的文本提示词引导生成方向。

Q: 如何选择合适的算法？

A: 如果已经有训练好的3DGS模型，优先用FreeFix；如果是稀疏视图输入，选GIFSplat； 如果场景有大面积遮挡，选ArtiFixer；如果需要实时应用，选One-Shot Refiner。

Q: 支持动态场景重建吗？

A: 是的，ArtiFixer支持动态场景和非刚性物体的时序重建，可以输入时序图像序列， 算法会自动保持时序一致性，适合人体、动物等动态对象的4D重建。
